
# ECommerce-Sales-And-Marketing-Audit-360

End-to-End Analytics Pipeline analyzing 100K+ rows of e-commerce data using Excel, Power BI, and Python.

---

## 📌 Executive Summary
An end-to-end data analytics project auditing **100,000+ transaction rows** across multi-channel e-commerce platforms (Facebook Ads, Google Ads, and Shopify Sales). This audit identifies channel acquisition performance, revenue leaks, order fulfillment metrics, and profitability drivers.

---

## 🛠️ Tech Stack & Methods
* **Python (Pandas & Jupyter Notebook):** Exploratory Data Analysis (EDA) and statistical metrics extraction.
* **Microsoft Excel:** Data preprocessing, pivot modeling, and cleaning.
* **Power BI (DAX):** Interactive executive dashboard with dynamic slicers and calculated measures.

---

## 📊 Key KPIs & Metrics Calculated
* **Total Net Revenue:** ~₹1.25B
* **Average Order Value (AOV):** ~₹12.47K
* **Return Rate:** ~8.02%
* **Ad Spend & Acquisition Efficiency:** Multi-channel ROAS and return analysis.
